# T03: Configure Expo build artifacts (app.json, eas.json, .env, prebuild)

Expand app.json with icon, splash, and build configuration. Create eas.json with internal build profiles (dev, preview). Create .env with EXPO_PUBLIC_API_BASE_URL for Android emulator (10.0.2.2:3000) and iOS simulator (localhost:3000). Then run `npx expo prebuild --clean` to generate android/ and ios/ native directories.

## Inputs

- `mobile/app.json`
- `mobile/package.json`

## Expected Output

- `mobile/app.json — expanded with icon, splash, android.adaptiveIcon, ios.infoPlist, extra.eas configuration`
- `eas.json — new file with internal build profiles (dev, preview) for Android and iOS`
- `mobile/.env — new file with EXPO_PUBLIC_API_BASE_URL=http://10.0.2.2:3000`
- `mobile/android/ — generated by expo prebuild`
- `mobile/ios/ — generated by expo prebuild`

## Verification

ls mobile/android/ && ls mobile/ios/ — both directories must exist after prebuild; eas.json must be valid JSON with `build.profiles` key
